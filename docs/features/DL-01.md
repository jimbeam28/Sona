## §1 用户视角

### 1.0 原始需求（用户原话逐字记录）

> 我想把B1、B3和B5做一下。（B5 = 离线缓存下载：单曲/文件夹下载到本地，断网可播）
> 裁决记录（2026-08-23，全部按推荐执行）：B5-1 双入口 / B5-2 DB v3 + Documents 目录 + .part 原子落盘 / B5-3 无断点续传 / B5-4 串行队列 / B5-5 done 且本地存在才走本地、丢失静默回退远程并标 failed / B5-6 零新鲜度检查 / B5-7 手动管理不自动清理 / B5-8 重启孤儿标 failed / B5-9 不做前台 Service。
> **入口形态变更声明（偏离已批准的 B5-1，需用户复核）**：原定「文件行加下载按钮」——勘察发现 AudioFileListTile 的 trailing 已被「下一首播」IconButton **常驻占用**（disabled 态也占位，file_list_item.dart:104-115），再塞一钮即窄屏挤压。裁决：文件级下载入口移入**既有文件长按菜单**（新增「下载此文件」项，零布局成本）；目录级入口维持 BRW-01 菜单第三项「下载此文件夹」。

### 1.1 这一功能干什么（一句话）

可以把单首歌或整个文件夹下载到手机里；下载完的歌播放时直接读本地不再走网络，没下载完或文件丢了就自动照旧在线播。

### 1.2 用户期望的场景

| ID | 你看到的样子 | 期望行为 |
|----|----|----|
| U1 | 长按一首歌 | 菜单里多一项「下载此文件」，点了提示已加入下载队列 |
| U2 | 长按一个文件夹（BRW-01 菜单） | 多一项「下载此文件夹」：扫描后整个文件夹的音频进队列 |
| U3 | 设置→存储→离线下载管理 | 列表显示当前连接的下载任务：等待中/下载中(进度条)/已完成(大小)/失败(可重试)；底部显示总占用 |
| U4 | 下载进行中 | 一次只有一个在下载；可取消（从列表消失） |
| U5 | 播放一首已下载的歌 | 秒开不走网络（飞行模式也能播）；锁屏控件一切如常 |
| U6 | 本地文件被系统清理掉 | 下次播放自动回到在线流式；列表里这条变失败，可重试 |
| U7 | 杀 App 时还有任务排队 | 重启后这些任务标失败，手动点重试继续 |
| U8 | 同一首歌重复点下载 | 提示已在下载列表中，不重复下 |
| U9 | 删除一条已完成记录 | 数据库记录和本地文件一起删 |

### 2.2 现有行为逆抽

- **loadAndPlay 源构建链**（playback_orchestrator.dart:170-195）：savedConnId/gate 校验 → passwordReader.readPassword(timeout 5s) → buildWithBasePath(baseUrl=webDavEffectiveBaseUrl(url, basePath), filePath=q.current.path, username, password) → player.setAudioSource → seek(startPositionMs)。本地命中时应**跳过密码读取**（省一次 secure storage 读）。

- **webdav 错误分类**：401/403→认证错误、404→不存在、其余非 2xx→服务器错误（:230-244）。GET 复用同族映射 WebDavException。

- **设置页结构**：SectionHeader + ListTile 平铺（:47-51 连接管理项形态参照）。

### 3.2 WebDAV GET 引擎

- **[DL-01-S3] downloadFile 流式下载**

```
WebDavClient.downloadFile(filePath, username, password, saveTo, onProgress):
  ① GET uri（Uri 编码同 AudioSourceBuilder.buildUriWithBasePath 规则）
     头 Authorization 用 AudioSourceBuilder.buildAuthHeader 复用
  ② send(request)——不加整体时长 timeout（大文件友好裁决）
  ③ 非 2xx → 按 webdav_client.dart:230-244 同族映射 WebDavException 抛出
  ④ 打开 saveTo 同名加 .part 后缀的 IOSink：逐 chunk write、累计 received、
     回调 onProgress(received, totalFromContentLengthHeader 可为 null)；
     chunk 间静默超时 30 秒视为死链 → 走失败路径
  ⑤ 成功 → 若 final 已存在先删 → File.rename 把 .part 改名成品 → 结束
  ⑥ 任何失败路径 → 尽力删除 .part（删除本身失败仅 debugPrint 不抛）
否定断言:
  - 成功路径不留 .part 残留
  - 失败路径 final 文件不被触碰（半截数据绝不冒充成品）
  - received 单调递增且不超过 total（total 为 null 时只报 received）
  - 请求不带 Range 与 If-Modified-Since 头（v1 无续传无新鲜度，B5-3/B5-6）
```

Code evidence: webdav_client.dart:222-244 请求与分类骨架

### 3.3 Domain 策略与核心引擎

- **[DL-01-S4] 本地文件名策略（纯函数，lib/features/downloads/domain/download_policy.dart）**

```
sanitizeBaseName(filePath):
  取 basename → 非法字符集替换为下划线。非法字符集 = 反斜杠、正斜杠、冒号、星号、
  问号、英文双引号、小于号、大于号、竖线（九个字符，用 String.split 条件映射实现，
  不写字面正则避免转义错误）→ 结果为空或全为点则整体替换为 file →
  超 120 字符截断但恒保留最后一段扩展名
resolveCollision(finalDir, baseName, existsProbe):
  无冲突用原名；冲突依次追加 _2 至 _999 后缀再探；999 耗尽抛 StateError（防御分支）
否定断言:
  - 输出不含任何路径分隔符（防目录穿越）
  - 扩展名恒保留（NasFile.classifyType 依赖扩展名）
  - existsProbe 为注入参数，函数自身不 import dart:io
```

- **[DL-01-S5] 串行泵（core/services/download_manager.dart）**

```
enqueueMany(items): 逐条 upsert(pending)；同连接同 path 已存在且状态非 failed → skip 该条
pump(): 重入保护（active 标志位）；循环取最早 pending 一条：
    setStatus(downloading, 0)
    → 计算本地路径 resolveCollision(dir, sanitizeBaseName(path), File.existsSync 包装探针)
      （探针在 manager 层实现，策略函数保持纯净）
    → client.downloadFile(..., onProgress 节流 250ms 写 updateProgress)
    → 成功 setStatus(done, remote_size)；失败 catch 后 debugPrint(redactUrlForLog) +
      setStatus(failed)；两者都继续循环下一条直到无 pending
cancel(id): 正在下载该条 → 置取消标志让引擎尽快返回 → deleteById；否则直接 deleteById
    （done 条目的 cancel/delete 同时删除本地文件）
retry(id): 仅 failed 可用 → setStatus(pending) → pump()
否定断言:
  - 任意时刻至多一条 downloading（INV2）
  - 泵活跃期间 enqueue 只插行不并发下载
  - 单条失败不阻断后续任务
  - 取消后 .part 残留被清理（复用 S3⑥ 清理语义 + deleteById 兜底删 .part）
```

依据：串行语义为本 spec 新增约束；错误卫生对齐 BUG-10 debugPrint 先例（browser_screen.dart:105-112）

## §6 算法样例

```
ALG [DL-01-ALG1-download-state-machine]:
  迁移表（列=事件，行=现态）:
             | enqueue(同path) | pump选中 | 下载成功 | 下载失败 | cancel | retry | 启动恢复
    pending   | skip            | downloading | -     | -        | 删除   | -     | failed
    downloading| skip           | -        | done     | failed   | 删除   | -     | failed
    done      | skip(提示已在)   | -        | -        | -        | 删除+删文件 | - | 不动
    failed    | 重新入队pending  | -        | -        | -        | 删除   | pending | 不动
  断言:
    - 任一行任一列结果唯一（穷举锁定 INV2）
    - done 是终态，唯一出口是用户删除
    - failed 经 retry/enqueue 两条路回 pending

ALG [DL-01-ALG2-resolveCollision]:
  输入 dir=/docs, base=song.mp3, existsProbe=[song.mp3 存在, song_2.mp3 存在]
  步骤: song.mp3 冲突 → song_2.mp3 冲突 → song_3.mp3 通过
  断言: 返回 song_3.mp3；existsProbe 调用序 [song.mp3, song_2.mp3, song_3.mp3]
  变体: base=a.b.c.mp3 → 冲突后缀插在扩展名前 a.b.c_2.mp3
```

## §8 平台特性与手动 QA

逐条核对 docs/dev/platform-pitfalls.md：

| 踩坑条目 | 是否触及 | 处置 |
|---|---|---|
| P17 超时分层 | 是 | S3② 明确不加整体时长超时；chunk 间 30s 静默判定死链（弱网大文件友好）；真机表现进 MQA |
| P14 async gap | 是 | S7/S8/S9 动作回调 await 后 context.mounted 检查 |
| P13 defunct State | 是 | 管理页 Timer.periodic 必须在 dispose 取消（State.dispose 配对，progress_provider.dart:174 先例） |
| P10 单一写源 | 否 | downloads 表独立，不触碰 progress/queue 写路径 |
| 平台存储权限 | 是 | 落getApplicationDocumentsDirectory 应用私有目录，免 WRITE_EXTERNAL_STORAGE 申请；卸载即清 |

**可行性依据（铁律 6）：**

- R1 `http.Client.send(StreamedRequest)` → StreamedResponse 逐 chunk 消费：**仓库现有同款**——webdav_client.dart:228-229 已用 send+timeout 消费响应流，本功能仅延长消费方式（listen chunks），包版本 http ^1.2.1 不变。
- R2 just_audio `AudioSource.file(String path)`：just_audio 0.9.40 公开 API（官方 API 文档 AudioSource.file 工厂构造），仓库未用过——**需最小验证**：dev-exe 阶段先跑一个只含 `AudioSource.file` 构造的单元冒烟（构造成功即可，不需真播），结论回填本文档；若 API 缺失则降级方案 LockCachingAudioSource 不采用（v1 明确不用缓存代理）。
- R3 `File.rename` 同分区原子性：dart:io 官方文档 rename 语义（目标存在时 Android/POSIX 下覆盖），配合 S3⑤ 先删后改名双保险。
- R4 IOSink 异步写 + stream listen chunk 计数：dart:io 标准 Stream 消费模式，test_database/fake 生态可直接注入字符串流测试。

**真机风险列（fake 测不到，只有真机会暴露）：**

| 风险 | 近似测试方案 | 测不了 → 进 mqa-backlog |
|---|---|---|
| B5-9 已批：App 切后台/Doze 冻结长下载 | 无前台 Service，Dart 定时器冻结即停 | MQA：真机后台 30 分钟下载存活率观察 |
| 大 FLAC（数百 MB）磁盘写满 | fake 注入 IOException 单测失败路径 | MQA：真机剩余空间 1GB 时下载 2GB 目录的行为 |
| 弱网 chunk 30s 静默误判（极慢但活着的链路） | fake_async 可近似 | MQA：弱网隧道实测误判率，必要时调参常量 |
| NAS 服务器对长连接 GET 的中途掐断 | fake 无法模拟 TCP 半开 | MQA：群晖/威联通实测失败率 |

本功能 manual_qa_required=true（涉及真实网络 IO + 本地文件系统 + 后台生命周期三重真机依赖）。
